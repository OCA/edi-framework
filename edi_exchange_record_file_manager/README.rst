Adds a "Manage File" button on EDI exchange records that contain a file
and are in an error state (``output_sent_and_error`` or
``input_processed_error``).

The button opens a wizard that lets the user either replace the exchange
file with a new one, or edit its content directly (with a code editor).
At the end the user can safely close the wizard.

Usage
=====

1. Open an EDI exchange record with a file, in state *Sent and error* or
   *Error on process*
2. Click on **Manage File**, setup *Replace file* or *Edit file* and
   click **Proceed**
3. Depending on the previous step's choice:

   -  Replace: download the current file (optional), upload the new one
      (mandatory) and **Proceed**
   -  Edit: change the content in the editor and **Proceed**
   -  In both cases: clicking on **Cancel** will discard your changes

4. Click **Close** to safely close the dialog window
