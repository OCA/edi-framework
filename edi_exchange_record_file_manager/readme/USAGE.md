1. Open an EDI exchange record with a file, in state *Sent and error* or *Error on process*
2. Click on **Manage File**, setup *Replace file* or *Edit file* and click **Proceed**
3. Depending on the previous step's choice:
    - Replace: download the current file (optional), upload the new one (mandatory) and **Proceed**
    - Edit: change the content in the editor and **Proceed**
    - In both cases: clicking on **Cancel** will discard your changes
4. Click **Retry** to retry the exchange, or **Close** to simply close the dialog window
