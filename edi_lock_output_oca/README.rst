Technical module locking fields of records once their EDI output was
sent, so that what the partner received and what Odoo holds do not drift
apart.

It provides:

- ``edi.lock.output.consumer.mixin``: a mixin refusing changes to a list
  of fields of records that are locked;
- the *Lock record on send* option on output exchange types: by default,
  a record is locked once an exchange of such a type was sent for it;
- the *Bypass EDI output lock* group, whose users can still change
  locked fields.

It has no functional effect until a model uses the mixin.

Use Cases / Context
===================

Once a document was sent to a partner (e.g. a transfer to a warehouse
management system), changing some of its fields in Odoo would make both
sides disagree. Each integration used to implement its own lock. This
module provides it once, for any model.

Usage
=====

This module is meant for developers. Inherit the mixin on the model to
lock and list the fields to lock:

.. code:: python

   class StockPicking(models.Model):
       _inherit = ["stock.picking", "edi.lock.output.consumer.mixin"]

       def _edi_lock_output_fields(self):
           return super()._edi_lock_output_fields() + ["partner_id", "scheduled_date"]

Then tick *Lock record on send* on the output exchange types that lock
the record. A change to a listed field of a record with a sent exchange
of such a type raises an error.

To lock on another condition, override ``_edi_lock_output_is_locked()``.
It is called on all the records being changed and returns the locked
ones. Add yours to the result of ``super()``, so that the records
already sent stay locked:

.. code:: python

       def _edi_lock_output_is_locked(self):
           return super()._edi_lock_output_is_locked() | self.filtered("is_frozen")

To change the error message, override ``_edi_lock_output_message()``.

The lock is bypassed:

- by the users of the *Bypass EDI output lock* group;
- by code, with the ``edi_lock_output_bypass`` key in the context, e.g.
  when processing the partner's own updates.
